# Mercy Maina — Portfolio

A personal portfolio built with Next.js, React and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validate

```bash
npm run typecheck
npm run lint
npm run build
```

## Project structure

```text
app/            Next.js layout, page and global styles
components/     Navigation, hero, about, work, toolkit, timeline and contact sections
data/           Portfolio content and TypeScript types
lib/             Small application utilities
public/images/  Project imagery
```
